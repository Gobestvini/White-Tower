# Знания проекта White Tower

Материалы перенесены 8 октября 2026 года из диалога [Создать полный GDD по видео](thread://01a11a46-d974-73e0-925a-60d08f1ade04?hostId=local). Они хранятся внутри проекта и доступны без исходного диалога или папки Downloads.

Пользователь запросил браузерную игру для всех возможных платформ с внешним видом в точности как на видео. Видео — основной визуальный референс; GDD версии 1.0 — подготовленная в исходном диалоге спецификация для разработки. Дополнительные правила и численные цели GDD сохраняют статус проектных предложений и предположений; перенос файлов не означает их отдельного утверждения или реализации.

## Как использовать

Перед первой реализацией прочитай разделы 1–9 GDD. Для художественной работы прочитай разделы 2–3 и 12–15 и открой соответствующие кадры и фрагменты видео. Требования к платформам, архитектуре и проверкам находятся в разделах 17–24. Раздел 25 перечисляет решения для сверки на первом срезе. Далее загружай только разделы по текущей задаче.

В GDD отдельно отмечены наблюдения по ролику и добавленные правила новой игры. Управление одним нажатием, расчёт счётчика, поглощение стрелок, защита от циклов, сохранения, объём кампании и бюджеты требуют проверки или продуктового уточнения при реализации. Разделы 2, 6, 7 и 25 особенно важны для этих границ. Текущую реализацию всегда проверяй по коду: сейчас проект содержит исходный Canvas 2D каркас.

В исходном диалоге сообщалось о проверке 24 страниц Word, HTML и четырёх примеров уровней. При переносе заново проверены целостность всех 17 файлов по SHA-256, ссылки Markdown на 12 кадров и чтение JSON. Проверки исходного диалога не являются проверками готовой игры в этом проекте.

Это файловая база проектных материалов. `pnpm context` читает отдельную память проверенных фактов по исходникам; GDD и видео не добавлены туда как подтверждённое поведение игры.
