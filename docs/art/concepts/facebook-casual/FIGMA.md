Они стоят справа, X = 10000 / 11100 / 12200 / 13300 / 14400, Y = 0 / 1872; размер каждого 941 × 1672. Кнопки и остальные исходные элементы сохранены отдельными PNG в исходных координатах. Чистый фон и панели находятся ниже них отдельными слоями. Фоны и дополнительные детали восстановлены и отличаются от мокапов.

## Каталог прозрачных элементов

[White Tower — Facebook Casual Concepts](https://www.figma.com/design/3qmmWSoZLpWIZjPDIZHSsZ?node-id=13-83)

Исправлено 10 октября 2026: прежние прямоугольные фрагменты `*-layers` удалены из документа. Вместо них загружены 150 самостоятельных PNG RGBA в 11 фреймах `*-alpha-assets`. В каждом элементе собственное изображение с прозрачностью по контуру; полная картинка экрана и прямоугольная маска не используются. Заливка внешних фреймов удалена. Десять исходных концептов сохранены сверху как референсы.

[Каталог PNG](../../../../assets/ui/facebook-casual/index.html), [manifest](../../../../assets/ui/facebook-casual/manifest.json), [инструкция для игры](../../../../assets/ui/facebook-casual/README.md).

Выбирайте именованную группу `Logo`, `Button-*`, `Setting-*-icon`, `Setting-*-label`, `Level-01` … `Level-30`. Каждый элемент можно перемещать и экспортировать отдельно. Текст и иконка внутри кнопки остаются частью её картинки. Игровые поля и башни остаются декоративными иллюстрациями. Четыре пустые панели восстановлены отдельно, потому что скрытые поверхности отсутствуют в исходных концептах; [промпты](PANEL-PROMPTS.md).

Для повторного импорта: `node tools/package-concept-assets.cjs`, затем импорт SVG из [alpha-boards](alpha-boards/). Внутри SVG каждый элемент содержит отдельный встроенный PNG. Для игры используйте оригинальные PNG из каталога: Figma может пересчитывать сглаживание при экспорте.

Проверки: все 11 загрузок успешны; исправленный фрейм 01 заменён дополнительно. В Figma проверены независимые именованные элементы и отсутствие заливки вокруг них. Контрольный экспорт `Button-export` из Figma дал PNG RGBA 312 × 81, с alpha от 0 до 255, размер совпал с исходником; максимальное отличие alpha после пересчёта Figma — 17/255. Все 150 PNG прошли проверку размеров, контрольных сумм, реальной alpha, прозрачного padding и отсутствия скрытого RGB при alpha=0. Контуры просмотрены на светлом и тёмном фоне. `pnpm check:full` — тесты и сборка прошли. Runtime игры не изменён.
