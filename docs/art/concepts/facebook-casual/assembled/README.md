# Экраны из отдельных элементов

Все десять экранов собраны в [Figma](https://www.figma.com/design/3qmmWSoZLpWIZjPDIZHSsZ?node-id=17-38). Новые фреймы `*-assembled` стоят справа от каталога ассетов, в пяти столбцах и двух рядах. Исходные концепты и каталог прозрачных элементов сохранены.

[Обзор десяти экранов](overview.html) · [Сравнение с мокапами и загрузка SVG](index.html).

146 исходных PNG встроены независимо, с исходными размерами и координатами из `origin`. Кнопки, логотипы, подписи, элементы настроек и уровни можно выбирать отдельно. Надпись и иконка внутри кнопки остаются частью PNG. Игровые поля и башни остаются цельными декоративными иллюстрациями.

Под элементами лежат десять чистых фоновых иллюстраций из `assets/ui/facebook-casual/backgrounds/`, восстановленных через image_gen; исходные полные мокапы в сборку не встроены. Поэтому скрытие кнопки открывает чистую поверхность. Четыре пустые панели используются повторно с масштабированием. Карточки строк, разделители, процент громкости и видимые части настроек под подтверждением сброса восстановлены отдельными слоями. Фон, скрытые поверхности и эти дополнительные детали отличаются от исходных мокапов; это не попиксельные копии.

Повторная сборка и проверка из корня проекта:

```powershell
node tools/assemble-concept-screens.cjs
python tools/validate-assembled-screens.py
pnpm check:full
```

SVG самодостаточны, каждый PNG встроен в именованную группу. `manifest.json` хранит состав и координаты, `figma-nodes.json` — размещение фреймов в документе. `background-prompts.json` содержит промпты восстановления фонов. Для игры используйте исходные PNG: экспорт Figma может пересчитать сглаживание.

Проверка в браузере: все десять сборок просмотрены рядом с референсами. В Figma проверены импорт и отдельные слои настроек; скрытие `Button-hint` открыло чистую панель без дубликата кнопки, затем видимость восстановлена. Игровой runtime не изменён.
