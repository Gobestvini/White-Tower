## 4. Требуемое поведение

- Export JSON включает версионированный прогресс/settings/устойчивую попытку. Import ограничивает размер/структуру, валидирует level data refs и все snapshots/Undo; неизвестная версия или неверные числа дают объяснимую ошибку.
- До замены показать понятное подтверждение, Cancel ничего не меняет. Применение одной подтверждённой транзакцией; ошибка записи не делает прогресс частично новым. Пользовательские тексты/файлы не пересылать наружу.
- Между вкладками использовать последнее подтверждённое сохранение с timestamp/revision и определённым tie-break. Проверка новой ревизии и запись выполняются атомарно для доступного backend; устаревшая вкладка на close не перезаписывает новое. localStorage fallback имеет документированный протокол и проверки гонок.
- Сопоставлять contentVersion/checksum. Совместимый upgrade сохраняет попытку, несовместимое изменение конкретного уровня сохраняет общий прогресс и перезапускает только попытку с объяснением в меню. Не мигрировать по одному совпадающему levelId.
- Завершённые/открытые IDs валидируются по новому каталогу; reset/import меняют generation и отменяют старые callbacks/searches. Ошибки storage не блокируют memory-only режим.
