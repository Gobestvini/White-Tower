- Создать ровно 8 новых уровней 13–20; 1–12 не переизобретать. Тема — запуск, слияние, порядок и Undo; новые поля 4–14 плиток, до 4×4, цели≥44 CSS px. Реконструкции видео имеют приоритет над общей размерной рекомендацией блока.

- Каждый JSON проходит общие campaign требования ниже; чередовать трудность, каждые 5–7 уровней лёгкая передышка. Последние уровни блока готовят более длинные redirect цепочки.
- Для 1–20 добавить review записи, включая уже проверенные 1–12 без ложного нового прохождения. После 20 Next ведёт на 21, если он опубликован; пока каталог заканчивается корректно.

Общий контракт кампании: schema/replay knownSolution и отсутствие допустимых циклических запусков проверяются валидатором; существование решения — обязательно, уникальность — нет. Для каждого нового уровня записать число плиток/стрелок, минимальные ходы только при доказанном поиске, порядок/ошибочные ветви, cameraPreset, время маршрута, время Hint, ручное прохождение и размер целей. Все поля читаемы при максимальной башне, не пересекают HUD/Undo, цели≥44 CSS px, максимальный нормальный ход целится в≤3.5 с. Hint штатно≤300 мс, максимум 2 с; при регулярном превышении перепроектировать уровень. Генерация/solver не заменяют человеческую проверку; новые файлы не должны быть простыми копиями одного решения.
