## 4. Требуемое поведение

- simulateMove(level, state,{u, v}) возвращает accepted/rejected, nextState, steps и events; в шагах фиксируются позиции, направление и высоты до/после поглощения. Вход immutable. Разрешены только активные стартовые стопки.
- Применить порядок раздела 6: стартовый redirect приоритетнее стрелки; шаг в существующую проходимую клетку; сложение высот; удаление целевой стрелки; затем направление пола назначения. По пустому полу продолжать, у края остановить и расходовать стартовую стрелку.
- Невозможный первый шаг не расходует стрелку, не создаёт ход. Для диагонали достаточно клетки назначения: отсутствие двух боковых соседей допустимо. Нельзя перескакивать отсутствующую клетку по вектору.
- Цикл проверять по полному состоянию маршрута: координаты, направление, оставшиеся неподвижные стопки и их стрелки. Возврат после нового поглощения не является тем же состоянием. При повторе или лимите 4096 шагов отклонить весь ход, не публиковать промежуточные изменения.
- Проверять сохранение N на каждом шаге; полученная башня пассивная. События поглощения содержат отображаемый X для анимации; логическая победа вычисляется в итоге, визуально показывается после остановки.
