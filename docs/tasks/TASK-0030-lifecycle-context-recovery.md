## 4. Требуемое поведение

- При webglcontextlost сохранить logical committedState/history, остановить представление и показать короткую загрузку; восстановить принадлежащую геометрию/материалы после context restored. - Повторный loss предлагает 2D режим, явный переход в устойчивый snapshot сохраняет Undo/completions. Полный отказ двух renderer показывает понятный Unsupported. Forced loss dev hooks не входят в release.
- Hidden/resume сохраняет временную позицию обычной анимации и приостанавливает audio; loader/Worker replies относятся к generation, старые не подключаются после restart/switch/dispose.
- Один RAF, один active input owner; dispose повторно безопасен. Счётчики GPU/DOM listeners/workers/audio nodes стабилизируются после повторных смен/Restart и освобождаются при teardown.
- Проверить 50 переходов уровня и отдельную 15 мин сессию; не считать JS heap единственным измерением GPU или iOS памяти. HMR cleanup сохранить.
