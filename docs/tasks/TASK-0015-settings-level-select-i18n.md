## 2. Проверенный контекст

Сверено 2026-10-08 после `69defa4`. TASK-0009/0012/0014 — done. `src/ui/hud.ts` держит минимальный Settings placeholder, Victory overlay отделён. `scene.snapshot()` уже возвращает selected level, completed IDs, unlockedLevel и сериализуемые `settings`; `scene.updateSettings`, `scene.clearProgress`, `scene.setLevelById` — интеграционные точки этой задачи.
