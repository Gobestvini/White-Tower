## 4. Требуемое поведение

- Выполнить ADR TASK-0002. Renderer принимает viewState, не выполняет simulateMove и не является владельцем gameState. При необходимости сменить сигнатуру scene.render вместе с main; не пытаться получить 2D и WebGL context одного уже созданного canvas.
- Фон #60C0FE, стартовая палитра GDD; слои шириной около 0.94, высотой 0.16, фаской 0.035–0.05 в мировых единицах. Каждая плитка отдельный читаемый слой; верхняя стрелка одинакового масштаба на любой высоте.
- Жёлтый пол с тонкими швами, белые шевроны, мягкая тень вверх-влево. Без bloom, текстур дерева, металла, частиц и чёрной обводки. Не использовать кадры ролика как финальные UI/field текстуры.
- Одна проекция для render и hit geometry; масштаб фиксируется при входе на уровень с учётом N слоёв. Reference canvas 720×1280. Не менять масштаб во время роста башни; новое содержание учитывает safe HUD области.
- Повторно использовать геометрию/материалы; resize учитывает CSS size и DPR≤2 на старте. Освободить все принадлежащие renderer GPU ресурсы и listeners при dispose; repeated reset не создаёт дубликаты.
- В docs/ASSETS.md записать источник (включая собственную процедурную геометрию), исходник/экспорт или путь генератора, версию, назначение и владельца ресурсов: плитка, пол, стрелка, шевроны, тень. Не считать PNG референса разрешением на использование чужого ассета.
