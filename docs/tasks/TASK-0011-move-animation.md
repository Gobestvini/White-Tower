## 4. Требуемое поведение

- createAnimationPlayer получает steps/events симулятора и строит отображаемые позы; start/update(dt)/snapshot/pause/reset/dispose не изменяют committedState. Единственный RAF принадлежит main.
- Начальные времена GDD: шаг 140–190 мс, поглощение 90–130 мс внутри шага, поворот 80–120 мс, остановка 100–160 мс. Показывать наклон/перекат, контакты и подъём каждого нового слоя, не плоское линейное скольжение.
- Счётчик обновлять по событиям поглощения; Won отображать после остановки. Пустые клетки не пропускать настолько быстро, что маршрут нечитаем. Цель действия≤3.5 с решается настройкой и дизайном маршрутов, не изменением правил.
- Hidden останавливает время анимации, возврат продолжает с той же позиции без catch-up. Restart/load/dispose отменяет устаревшие timelines; completion идемпотентен по generation ID.
- Reduced motion отключает пульсацию/выраженный перекат, оставляет короткие≤100 мс перемещения или мгновенное обновление. Ускорение после обучения — настройка представления, не скорость симулятора.
