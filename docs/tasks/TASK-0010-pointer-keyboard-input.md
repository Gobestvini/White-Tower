## 4. Требуемое поведение

- Pointerdown запоминает первичный контакт, target и CSS позицию; pointerup запускает только ту же цель при смещении≤12 CSS px. Pointercancel/blur/hidden отменяют контакт, второй палец игнорируется; drag/swipe не запускает.
- Hit test использует displayedState и общую проекцию, учитывает глубину и видимость верхней грани. Выбирать ближайшую доступную грань, без нажатия через переднюю башню. Добавка к цели не перехватывает соседнюю.
- Стрелки клавиатуры циклически выбирают активные стопки по экранным координатам; Enter/Space запускают. Z/Ctrl+Z Undo, R Restart, Escape переключает Menu phase контроллера (визуальный экран меню обеспечивает TASK-0015). Tab остаётся DOM навигацией; текстовые поля редактора и меню не перехватываются игрой.
- В Animating команды не копятся. Для UI применить тот же controller, а не независимые обработчики движения. Touch suppression ограничить игровой поверхностью, сохранять работу страниц/меню.
- Сохранить очистку keys и disposal из createInput. Обновить browser-check: нынешний script проверяет пустой elapsed и кнопки Пауза/Сброс; заменить контракт после появления игры, не оставлять ложный зелёный тест.
