## 4. Требуемое поведение

- Проверить 320×568, 360×640, 390×844, 412×915, 768×1024, 1024×768, 1366×768, 1920×1080. Учитывать доступный viewport, dynamic browser bars и safe-area; uniform scale, background тот же. Landscape/split-view сохраняют доступ к Undo.
- Reference720×1280 остаётся без изменения пиксельной композиции. На остальных экранах допускается боковое размещение меню; поле не растягивается. Для новых уровней оценивать максимальную башню N и touch цели≥44 CSS px, предпочтительно 48.
- DOM кнопки имеют имена/focus; рядом с canvas доступное описание активных стрелок, координат, высот, направлений и X/N. Keyboard выбор синхронизирован с видимой подсветкой. Не оглашать каждый animation frame через live region.
- Reduced motion/system preference и high contrast доступны через настройки, визуальный signal дублирует звук/цвет. Временно закрытая башней активная грань остаётся выбираемой клавиатурой.
- Проверить screen reader в реальном прохождении с Undo, victory и меню; aria-label сам по себе не означает полную доступность. Конкретные ограничения записать; недоступный реальный телефон не заменять эмуляцией.
