## 4. Требуемое поведение

- Lv.1 после 2 с без действия показывает Tap the arrow без перекрытия поля, после первого запуска скрывает. Lv.2–11 обучают формой; не добавлять отдельный обязательный tutorial modal.
- Hint доступна из Settings, бесплатна, не делает ход. Solved выделяет первую активную стрелку пути текущего state. Если текущий state unsolvable, проверить предыдущий Undo snapshot и сообщить Undo the last move, когда это обосновано.
- Штатная цель 300 мс; после задержки индикатор, жёсткий бюджет 2 с. Timeout не выбирает случайную стрелку и не объявляет тупик; предложенная отмена после бюджета обозначается советом, а не доказательством решения.
- При нескольких стопках без допустимых запусков или доказанном unsolvable через 0.6 с после остановки показать под Undo Try undoing a move на 2 с. Timeout никогда не запускает этот вывод; скрытое состояние и устаревшие ответы игнорируются.
- Смена попытки/уровня/Undo/restart/закрытие меню отменяет pending запрос. Подсказка не раскрывает весь путь и не меняет числа ходов/историю.
