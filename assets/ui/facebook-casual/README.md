# White Tower: прозрачные ассеты

150 самостоятельных PNG RGBA: 146 элементов с десяти концептов и 4 чистые основы панелей. [Галерея](index.html) позволяет проверить элементы на шахматке, светлом, тёмном и голубом фоне и скачать каждый PNG.

В игре используйте PNG непосредственно из этой папки. Цветовая подложка и шахматка в файлы не входят. Внешний контур имеет alpha; внутри кнопок сохранены исходные цвет, блик, иконка и надпись. Вокруг каждого файла 4 px прозрачного отступа, у восстановленных панелей — 8 px. Тексты на кнопках запечены в изображение; отдельные подписи настроек экспортированы отдельно. Набор не содержит новых состояний hover/pressed или локализаций.

`manifest.json` содержит размеры, имена, координаты источника, смещение после обрезки, padding, контрольные суммы и результаты проверки alpha. `origin` — позиция верхнего левого угла PNG, включая padding, в исходном концепте 941 × 1672 px. Панели без содержимого восстановлены генеративно: скрытых пикселей в концептах нет. Они отмечены полем `source` и не являются точными копиями исходного фона.

Игровые поля, башни и острова здесь декоративные иллюстрации. Это не спрайты отдельных плиток и не модели для интерактивной игровой геометрии. Статичный счётчик из концепта также остаётся картинкой.

## Figma

[Документ](https://www.figma.com/design/3qmmWSoZLpWIZjPDIZHSsZ?node-id=13-83): 10 исходных концептов и 11 наборов `*-alpha-assets`. Каждая именованная группа содержит собственный прозрачный PNG. Выбирайте всю группу элемента; его можно перемещать и экспортировать отдельно. Заливка внешних фреймов удалена. Прежние прямоугольные фрагменты `*-layers` удалены.

Для точного исходного PNG предпочтительны файлы этой папки: Figma может пересчитать сглаживание при экспорте. Контрольный экспорт `Button-export` из Figma сохранил размер 312 × 81, RGBA и прозрачность; максимальное отличие alpha от исходного файла составило 17/255.

## Воспроизведение

Из корня проекта, с Python и установленными `Pillow`, `numpy`, `opencv-python-headless`:

```powershell
python tools/extract-concept-assets.py
```

Это заново создаёт 146 вырезанных элементов, сохраняя записи четырёх готовых панелей. Панели уже сохранены в `panels/`; для их повторной генерации нужны [промпты](../../../docs/art/concepts/facebook-casual/PANEL-PROMPTS.md) и соответствующие концепты. Для повторной обработки сырых результатов положите `panel-*-raw.png` в `artifacts/alpha-review/` и запустите `python tools/prepare-transparent-panels.py`. Частичная нарезка `--screens 01-gameplay` сохраняет остальные записи.

```powershell
node tools/package-concept-assets.cjs
python tools/validate-concept-assets.py
pnpm check:full
```

SVG из `docs/art/concepts/facebook-casual/alpha-boards/` служат для импорта в Figma: каждый PNG встроен отдельно. Проверка отвергает отсутствующую alpha, непрозрачную прямоугольную подложку, загрязнённый padding, скрытый RGB при alpha=0, неверные размеры и контрольные суммы. Финальные элементы просмотрены на светлом и тёмном фоне. Игровой runtime в этой поставке не изменён.
